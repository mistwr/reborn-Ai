## 🚀 Como Começar

### 1. Clone & Setup
```bash
git clone https://github.com/mistwr/reborn-Ai.git
cd reborn-Ai
git checkout nextauth-url-warning
pnpm install
```

### 2. Configure .env.local
```env
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=dev-secret-key

AI_MODEL=deepseek-chat
AI_VISION_MODEL=gpt-4-vision-preview
AI_GATEWAY_API_KEY=default
```

### 3. Run Dev Server
```bash
pnpm dev
# http://localhost:3000
```

### 4. Access Pro Tab
- Clique no ícone de coroa (👑 Pro) na sidebar
- Explore os 4 módulos
- Crie conteúdo sem limites
